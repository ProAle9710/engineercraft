# Tarea 20 — Arreglos int[]

Si prefieres inglés, abre `TASK.md`.

## Objetivo
Crear arreglos de números con `int[]`.

## Sintaxis

```java
int[] scores = {90, 75, 88};
```

Misma idea que `String[]`, pero cada valor es un `int`.

## Dónde trabajar
- Archivo: `Starter.java`

## Pasos

El ejemplo de arriba muestra la sintaxis **nueva**. Escribe tus propios arreglos.

1. Crea int[] `scores` con 3 números.
2. Crea int[] `ages` con 4 números.
3. Crea int[] `prices` con 3 números.
4. Mira las líneas de print: leen valores con `[0]`, `[1]`, ...
   Los índices se practican más en la siguiente tarea.

## Listo cuando
Existan tres `int[]` y el programa corra.

## Cómo ejecutar

Sigue estos pasos. No ejecutes los comandos desde una carpeta cualquiera.

### 1) Abre una consola (terminal)

- **VS Code**: menú **Terminal → New Terminal**
- **IntelliJ IDEA**: menú **View → Tool Windows → Terminal**
- O abre **PowerShell** / **Símbolo del sistema** en Windows

### 2) Entra a ESTA carpeta

```bash
cd student-tasks\task-20-int-array
```

### 3) Compila: `javac Starter.java`
### 4) Ejecuta: `java Starter` (no `java Starter.java`)
