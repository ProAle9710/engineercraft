# Task 20 — int Arrays

## Goal
Create arrays of numbers using `int[]`.

## Syntax

```java
int[] scores = {90, 75, 88};
```

Same idea as `String[]`, but every value is an `int`.

## Where to work
- File: `Starter.java`

## Steps

The example above shows the **new** syntax. Write your own arrays.

1. Create int[] `scores` with 3 numbers.
2. Create int[] `ages` with 4 numbers.
3. Create int[] `prices` with 3 numbers.
4. Look at the print lines: they read values with `[0]`, `[1]`, ...
   You will practice indexes more in the next task. For now, just create the arrays.

## Done when
Three `int[]` arrays exist and the program runs.
## How to run

Follow these steps carefully. Do not run the commands from a random folder.

### 1) Open a console (terminal)

- **VS Code**: menu **Terminal → New Terminal** (or the shortcut shown in that menu)
- **IntelliJ IDEA**: menu **View → Tool Windows → Terminal** (or the Terminal tab at the bottom)
- Or open **PowerShell** / **Command Prompt** on Windows

### 2) Go to THIS task folder

You must be inside the folder that contains `Starter.java`.

Example (change the path if needed):

```bash
cd student-tasks\task-20-int-array
```

Check with:

```bash
dir
```

You should see `Starter.java` and `TASK.md`.

### 3) Compile

```bash
javac Starter.java
```

This creates `Starter.class`. If you see errors, fix your code and compile again.

### 4) Run

```bash
java Starter
```

- Correct: `java Starter`
- Wrong: `java Starter.java`
- Wrong: running this from another folder
