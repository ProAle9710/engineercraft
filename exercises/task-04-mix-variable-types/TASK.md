# Task 04 — Mix Variable Types

## Goal
In one file, create variables of different types using correct Java syntax.

## Remember
| Type | Example |
|------|---------|
| String | `String username = "Maria";` |
| int | `int level = 20;` |
| boolean | `boolean isPremium = true;` |

## Where to work
- File: `Starter.java`

## Steps

Do **not** copy a full line from the table above. Write each variable yourself.

1. Create a String named `username`.
2. Create an int named `level`.
3. Create an int named `score`.
4. Create a boolean named `isPremium`.
5. Create a String named `country`.

## Thinking check
Ask yourself for each value: *Is this text (String), a whole number (int), or true/false (boolean)?*

## Done when
All 5 variables use the correct type before the name.

## How to run

Follow these steps carefully. Do not run the commands from a random folder.

### 1) Open a console (terminal)

- **VS Code**: menu **Terminal → New Terminal** (or the shortcut shown in that menu)
- **IntelliJ IDEA**: menu **View → Tool Windows → Terminal** (or the Terminal tab at the bottom)
- Or open **PowerShell** / **Command Prompt** on Windows

### 2) Go to THIS task folder

You must be inside the folder that contains `Starter.java`.

Example (change the path if needed):

```bash
cd student-tasks\task-04-mix-variable-types
```

Check with:

```bash
dir
```

You should see `Starter.java` and `TASK.md`.

### 3) Compile

```bash
javac Starter.java
```

This creates `Starter.class`. If you see errors, fix your code and compile again.

### 4) Run

```bash
java Starter
```

- Correct: `java Starter`
- Wrong: `java Starter.java`
- Wrong: running this from another folder
