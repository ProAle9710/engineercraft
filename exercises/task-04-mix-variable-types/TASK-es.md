# Tarea 04 — Mezclar tipos de variables

Si prefieres inglés, abre `TASK.md`.

## Objetivo
En un solo archivo, crear variables de distintos tipos con sintaxis correcta de Java.

## Recuerda
| Tipo | Ejemplo |
|------|---------|
| String | `String username = "Maria";` |
| int | `int level = 20;` |
| boolean | `boolean isPremium = true;` |

## Dónde trabajar
- Archivo: `Starter.java`

## Pasos

**No** copies una línea completa de la tabla. Escríbela tú.

1. Crea un String llamado `username`.
2. Crea un int llamado `level`.
3. Crea un int llamado `score`.
4. Crea un boolean llamado `isPremium`.
5. Crea un String llamado `country`.

## Comprobación
Para cada valor pregúntate: *¿es texto (String), un entero (int) o true/false (boolean)?*

## Listo cuando
Las 5 variables tengan el tipo correcto antes del nombre.

## Cómo ejecutar

Sigue estos pasos. No ejecutes los comandos desde una carpeta cualquiera.

### 1) Abre una consola (terminal)

- **VS Code**: menú **Terminal → New Terminal**
- **IntelliJ IDEA**: menú **View → Tool Windows → Terminal**
- O abre **PowerShell** / **Símbolo del sistema** en Windows

### 2) Entra a ESTA carpeta

```bash
cd student-tasks\task-04-mix-variable-types
```

### 3) Compila

```bash
javac Starter.java
```

### 4) Ejecuta

```bash
java Starter
```

- Correcto: `java Starter`
- Incorrecto: `java Starter.java`
