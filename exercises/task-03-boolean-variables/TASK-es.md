# Tarea 03 — Variables boolean

Si prefieres inglés, abre `TASK.md`.

## Objetivo
Crear variables **boolean**. Un boolean solo es `true` o `false`.

## Sintaxis correcta

```java
boolean isStudent = true;
boolean isSleeping = false;
```

Importante:
- **No** pongas comillas alrededor de `true` / `false`.
- Correcto: `true`
- Incorrecto: `"true"` (eso es un String, no un boolean)

## Dónde trabajar
- Archivo: `Starter.java`

## Pasos

1. Crea `boolean isStudent = true;`
2. Crea `boolean hasLaptop = true;` o `false` (tú eliges).
3. Crea `boolean likesMath = true;` o `false`.
4. Crea `boolean isOnline = false;`

## Listo cuando
Tengas 4 boolean con `boolean name = true/false;`

## Cómo ejecutar

Sigue estos pasos. No ejecutes los comandos desde una carpeta cualquiera.

### 1) Abre una consola (terminal)

- **VS Code**: menú **Terminal → New Terminal**
- **IntelliJ IDEA**: menú **View → Tool Windows → Terminal**
- O abre **PowerShell** / **Símbolo del sistema** en Windows

### 2) Entra a ESTA carpeta

```bash
cd student-tasks\task-03-boolean-variables
```

### 3) Compila

```bash
javac Starter.java
```

### 4) Ejecuta

```bash
java Starter
```

- Correcto: `java Starter`
- Incorrecto: `java Starter.java`
