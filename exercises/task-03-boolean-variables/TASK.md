# Task 03 — Boolean Variables

## Goal
Create **boolean** variables. A boolean is only `true` or `false`.

## Correct syntax

```java
boolean isStudent = true;
boolean isSleeping = false;
```

Important:
- Do **not** put quotes around `true` / `false`.
- Correct: `true`
- Wrong: `"true"` (that is a String, not a boolean)

## Where to work
- File: `Starter.java`

## Steps

1. Create `boolean isStudent = true;`
2. Create `boolean hasLaptop = true;` or `false` (your choice).
3. Create `boolean likesMath = true;` or `false`.
4. Create `boolean isOnline = false;`

## Done when
You have 4 boolean variables using `boolean name = true/false;`

## How to run

Follow these steps carefully. Do not run the commands from a random folder.

### 1) Open a console (terminal)

- **VS Code**: menu **Terminal → New Terminal** (or the shortcut shown in that menu)
- **IntelliJ IDEA**: menu **View → Tool Windows → Terminal** (or the Terminal tab at the bottom)
- Or open **PowerShell** / **Command Prompt** on Windows

### 2) Go to THIS task folder

You must be inside the folder that contains `Starter.java`.

Example (change the path if needed):

```bash
cd student-tasks\task-03-boolean-variables
```

Check with:

```bash
dir
```

You should see `Starter.java` and `TASK.md`.

### 3) Compile

```bash
javac Starter.java
```

This creates `Starter.class`. If you see errors, fix your code and compile again.

### 4) Run

```bash
java Starter
```

- Correct: `java Starter`
- Wrong: `java Starter.java`
- Wrong: running this from another folder
