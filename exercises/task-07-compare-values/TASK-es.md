# Tarea 07 — Comparar valores

Si prefieres inglés, abre `TASK.md`.

## Objetivo
Comparar dos números y guardar el resultado en un boolean.

## Operadores de comparación
| Operador | Significado | Ejemplo |
|----------|-------------|---------|
| `>` | mayor que | `5 > 3` → `true` |
| `<` | menor que | `2 < 1` → `false` |
| `==` | igual a | `4 == 4` → `true` |

## Dónde trabajar
- Archivo: `Starter.java`

## Pasos

1. Crea int `myScore`.
2. Crea int `highScore`.
3. Crea boolean `isNewRecord` usando `>` (nuevo — mira la tabla).
4. Crea boolean `isExactMatch` usando `==`.
5. Asigna String `resultMessage` con if/else:
   - Récord nuevo → New record!
   - Si no → Keep practicing

## Listo cuando
Cambies los números y los boolean y el mensaje tengan sentido.
