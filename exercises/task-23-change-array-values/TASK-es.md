# Tarea 23 — Cambiar un valor dentro de un arreglo

Si prefieres inglés, abre `TASK.md`.

## Objetivo
Aprender que las casillas de un arreglo se pueden actualizar después de crearlo.

## Idea

```java
String[] names = {"Ana", "Luis", "Maria"};
names[1] = "Carlos"; // ahora la posición 1 es "Carlos"
```

**No** vuelves a escribir el tipo al cambiar una casilla.

## Dónde trabajar
- Archivo: `Starter.java`

## Pasos

1. Crea String[] `team` con 3 nombres (práctica).
2. Cambia la primera casilla a Alex (nuevo — mira la idea de arriba).
3. Cambia la última casilla a Chris.
4. Crea int[] `lives` con tres 3.
5. Cambia la casilla del medio a 2.
6. Crea String `leader` del índice 0 de `team`.

## Listo cuando
Los valores impresos muestren tus cambios.

## Cómo ejecutar

Sigue estos pasos. No ejecutes los comandos desde una carpeta cualquiera.

### 1) Abre una consola (terminal)

- **VS Code**: menú **Terminal → New Terminal**
- **IntelliJ IDEA**: menú **View → Tool Windows → Terminal**
- O abre **PowerShell** / **Símbolo del sistema** en Windows

### 2) Entra a ESTA carpeta

```bash
cd student-tasks\task-23-change-array-values
```

### 3) Compila: `javac Starter.java`
### 4) Ejecuta: `java Starter` (no `java Starter.java`)
