# Tarea 09 — Perfil de usuario para Firebase

Si prefieres inglés, abre `TASK.md`.

## Objetivo
Crear un perfil de usuario como variables Java (datos que más adelante podrías guardar en Firebase).

## Dónde trabajar
- Archivo: `Starter.java`

## Pasos

Escribe las variables tú.

1. Crea String `userId` (idea: user_001).
2. Crea String `displayName`.
3. Crea String `email`.
4. Crea int `age`.
5. Crea boolean `emailVerified` en false.
6. Crea boolean `profileReady` (true si llenaste el nombre).

## Listo cuando
Todas usen tipos correctos: `String`, `int`, `boolean`.

## Cómo ejecutar

Sigue estos pasos. No ejecutes los comandos desde una carpeta cualquiera.

### 1) Abre una consola (terminal)

- **VS Code**: menú **Terminal → New Terminal**
- **IntelliJ IDEA**: menú **View → Tool Windows → Terminal**
- O abre **PowerShell** / **Símbolo del sistema** en Windows

### 2) Entra a ESTA carpeta

```bash
cd student-tasks\task-09-firebase-user-profile
```

### 3) Compila: `javac Starter.java`
### 4) Ejecuta: `java Starter` (no `java Starter.java`)
