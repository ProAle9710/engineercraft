# Tarea 19 — Tu primer arreglo (String[])

Si prefieres inglés, abre `TASK.md`.

## Objetivo
Aprender qué es un **arreglo** y crear un arreglo de `String`.

## ¿Qué es un arreglo?

Una variable que guarda **muchos valores** del mismo tipo, en una fila con posiciones.

```
índice:  0        1        2
valor: "Ana"   "Luis"   "Maria"
```

## Sintaxis correcta

```java
String[] names = {"Ana", "Luis", "Maria"};
```

- `String[]` = un arreglo de Strings
- `names` = el nombre de la variable
- `{ ... }` = los valores
